# RNR Cricket Sporting Equipment

Premium e-commerce website for RNR Cricket Sporting Equipment, based in the Cayman Islands.

## Sports Covered
- **Cricket** (primary focus)
- **Pickleball** (full Selkirk catalog integrated)
- **Netball**
- **Rugby**
- **Football**

## Tech Stack
- React (JSX)
- Sora + Barlow Condensed typography
- Selkirk product catalog with real product images

## Brand Colors
| Color | Hex |
|-------|-----|
| Primary | `#36BFB1` |
| Secondary | `#038C73` |
| Accent | `#02735E` |
| Dark | `#014034` |
| Base | `#0D0D0D` |

## Features
- Full pickleball catalog (36+ Selkirk products)
- Category filtering and sorting
- Shopping cart with slide-out drawer
- Product performance stat bars (power, control, spin)
- Newsletter signup
- Contact form with team/club orders
- Responsive design
