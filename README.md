# RNR Cricket & Equipment

Cayman Islands' premier sporting equipment and custom uniform website.

## Sports Categories
- **Cricket** — Bats, pads, gloves, helmets, balls, bags, shoes
- **Pickleball** — Paddles, balls, nets, bags, shoes
- **Netball** — Balls, shoes, bibs, posts
- **Rugby** — Balls, boots, protection, headguards, training
- **Football** — Balls, boots, shin guards, gloves, training

## Features
- Multi-sport equipment store with real product data and images
- Custom uniforms & team wear section
- Working shopping cart with quantity controls
- Category filtering and search
- Responsive design
- Contact form with enquiry types
- Island-tech teal color scheme

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Tech Stack
- React 18
- Vite 6
- Sora + Space Grotesk fonts
- Pure CSS-in-JS (no external CSS framework)
